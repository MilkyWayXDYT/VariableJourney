# Приключения переменной

Приключения переменной - это обучающая компьютерная игра в жанре головоломки от третьего 
лица предназначена для интерактивного изучения основ программирования.

Достоинствами игрового продукта являются прямая визуализация типов данных через уникальные механики,
а также метафоричная архитектура уровней, наглядно объясняющая логику условий и циклов через геймплей,
дополненная теорией. В отличие от аналогов пользователь не программирует, и при этом изучает 
программирование за счет ассоциаций, а после прохождения игра полученные знания проверяются с помощью 
теста, результаты которого экспортируются в Excel таблицу.

---

Игра имеет 5 уровней, главное меню и тестирование в конце.

## 1 уровень - типизация

Уровень рассказывает что такое переменная и зачем нужна типизация. 

На уровне игрок получает три типа и механики, при прохождении трех мини игр:

### int - подобие настольного баскетбола

Пользователь получает возможность прыгать, в левом нижнем углу отображен текущий тип.

### string - распутывание веревки

При прохождении уровня игрок получает два типа - string - гарпун и bool - взаимодействие с рычагами
и дверьми (для дальнейшего прохождения), с помощью кнопок 1 и 2 можно листать типы, один тип - 
одна механика

### bool - лабиринт с перекрытыми путями

После прохождения игрок попадает на следующий уровень.

## 2 уровень - инициализация и If/else

В начале говорится о важности инициализации, так как игрок только с типом, он не может пройти через if 
и попадает к else.

У else надо пройти полосу препятствий используя полученные механики. Игрок может притягивать к себе
синие платформы, притягиваться к оранжевым, прыгать по серым и передвигать их с помощью рычагов.

После прохождения полосы у else игрок попадает снова к if и проходит на следующий уровень.

## 3 уровень - while

Уровень цикличен, игроку необходимо выполнить условие для выхода из цикла, если он не успевает за
ограниченное время, уровень перезапускается.

Игроку необходимо собрать 5 битов, один 0 и четыре 1, собранные биты переводятся из двоичной системы
в десятичную и получившееся число влияет на следующий уровень - порядок собранных битов имеет значение.

## 4 уровень - for

Полученное число на прошлом уровне является числом комнат. Уровень сделан на основе игры Doors. 

Всего на уровне 4 комнаты:

### Простая комната

Игроку надо дойти до двери в следующую комнату.

### Комната с рычагом в рандомном месте

В одной из 6 точек в маленьком лабиринте спавнится рычаг, который открывает дверь на следующий уровень.

### Комната с рычагами

В комнате 5 рычагов, при нажатии на 4 из них создается дверь в следующую комнату, один случайный 
из 5 рычагов добавляет к двери глюк из-за чего комната становится глючной

### Коридор

В коридоре несколько дверных проемов, создаются правильная и глючная двери. Также коридор является 
последней комнатой, там создаются глючная дверь, следующая по очереди и конечная.

Если игрок выходит в следующую дверь - уровень перезапускается, так как он "вышел за границы"

### Глючная комната

При попадании в эту комнату уровень также перезапускается

### После прохождения игры, пользователю открывается тест, для проверки полученных знаний, результаты теста выгружаются в csv файл на рабочий стол
